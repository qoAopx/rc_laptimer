# RC Car Lap Timer — ESP32 + 光電センサ / BLE / LoRa

光電式センサでRCカーの通過を検出し、ESP32でラップタイムを計測するラップタイマーです。20×4 I2C LCDへ表示し、ラップ確定時にはBLEとLoRa E220の両方へ同じデータを送信します。

Web Bluetooth対応の受信画面は[docs/](docs/)です。GitHub Pagesで公開する場合は`docs`を公開フォルダに設定してください。

## 機能

- 初回の有効なセンサ通過で計測を開始し、以後の通過でラップを確定
- 遮光時間のしきい値（0〜200 ms）によるノイズ除去
- 最低500 msを保証するデッドタイム（ボリューム設定は0〜5.0 s）
- LCDへの現在経過時間、ベスト、直近ラップ、ひとつ前のラップの表示
- LED点滅と4 kHz・50 msのブザーで通過を通知
- BLE Notify / IndicateとLoRa E220への`Lap: xx.xx`送信
- BLE切断後の再アドバタイズ、設定スイッチのデバウンス、ADC値のEWMA平滑化

## 接続構成

```text
光電センサ ───── GPIO 26 ┐
感度ボリューム ── GPIO 32 │
デッドタイムVR ── GPIO 33 │
設定スイッチ ──── GPIO 14 │
                            ├─ ESP32 ─ I2C (GPIO 21/22) ─ LCD 20×4
LED ───────────── GPIO 17 │       ├─ GPIO 19 ─ ブザー
                            │       ├─ BLE ─ スマートフォン / Webクライアント
                            │       └─ UART等 ─ E220-900T22S/L(JP) LoRaモジュール
```

### ESP32のピン

| GPIO | 接続先 | 備考 |
| --- | --- | --- |
| 26 | 光電センサ | `CHANGE`割り込み。遮光時をHIGHとして扱う |
| 32 | 感度ボリューム | ADC、遮光時間しきい値 |
| 33 | デッドタイムボリューム | ADC、再検出禁止時間 |
| 17 | LED | 通過・再アーム時に点滅 |
| 19 | ブザー | 通過時に鳴動 |
| 14 | 設定スイッチ | `INPUT_PULLUP`。LOWで設定表示モード |
| 21 / 22 | LCD SDA / SCL | I2C、LCDアドレスは`0x27` |

### LoRa E220の既定ピン

LoRaのピン定義と通信設定は、同梱の[esp32_e220900t22s_jp_lib_v2.h](esp32_e220900t22s_jp_lib_v2.h)にあります。既定ではM0=4、M1=13、ESP32 RX=18、TX=23、AUX=34、UART=9600 bpsです。スケッチはライブラリの既定設定値を書き込み、ノーマルモードに切り替えます。モジュールの初期化は最大5回試行し、失敗してもラップ計測とBLEは動作します。

## 使い方

1. センサ、LCD、LED、ブザー、必要に応じてE220を配線します。
2. Arduino IDEで[ESP32_RC_LAPTIMER_IR.ino](ESP32_RC_LAPTIMER_IR.ino)をESP32へ書き込みます。ボード設定はスケッチ先頭の`@arduino-config`を参照してください。
3. 起動後、LEDが2回点滅し、LCDに`LAP TIMER READY`と`PASS SENSOR TO START`が表示されたら準備完了です。
4. 最初の有効な遮光で計測を開始します。このときBLE/LoRaには`Lap:  0.00`が送られます。
5. 次回以降の有効な遮光ごとにラップタイムが確定します。確定時はLED、ブザー、BLE、LoRaで通知されます。

### 調整

| 設定 | 範囲 | 説明 |
| --- | --- | --- |
| SENSOR TH | 0〜200 ms | 遮光がこの時間以上継続したときだけ通過として確定。短いノイズを除去します。 |
| DEAD TIME | ボリューム表示 0〜5.0 s | ラップ確定後の再検出禁止時間。内部では最低500 msに制限されます。 |

ADC値は100 msごとに読み取り、EWMA（係数0.1）で平滑化します。設定スイッチをLOWにすると、設定値とセンサの`BLOCK` / `CLEAR`状態をLCDで確認できます。

## LCD表示

### 待機中

```text
--- RC LAP TIMER ---
   LAP TIMER READY
PASS SENSOR TO START
PowerON(NormalStart)
```

最下行には前回のリセット理由が表示されます。

### 計測中

```text
TIME :00:12.34
BEST :00:11.89     OK
CURR :00:12.34     L+
PREV :00:13.01     B+
```

| 項目 | 内容 |
| --- | --- |
| TIME | 次の通過までの現在ラップ経過時間 |
| BEST | セッション内の最短ラップ |
| CURR / PREV | 直近 / ひとつ前に確定したラップ |
| `OK` / `__` | センサが受付可能 / デッドタイム中 |
| `L+` / `L-` | LoRaの初期化成功 / 失敗 |
| `B+` / `B-` | BLE接続中 / 未接続 |

LCDは約333 msごとに更新し、3分ごとにI2C LCDを再初期化して表示復旧を試みます。

### 設定表示モード

設定スイッチをLOWにすると、通常のラップ表示の代わりに次の内容を表示します。

```text
--- SETTING MODE ---
SENSOR TH:   10 ms OK
DEAD TIME:  2.0 s L+
SENSOR   : CLEAR    B+
```

右端の`OK` / `__`、`L+` / `L-`、`B+` / `B-`は計測画面と同じ状態表示です。

## 通信仕様

### BLE

| 項目 | 値 |
| --- | --- |
| デバイス名 | `RC_LAPTIMER` |
| Service UUID | `12345678-1234-1234-1234-1234567890ab` |
| Characteristic UUID | `abcdefab-1234-5678-1234-abcdefabcdef` |
| プロパティ | READ / NOTIFY / INDICATE |
| 送信出力 | +9 dBm |
| ペイロード | `Lap:%6.2f`（秒。例: `Lap: 12.34`） |

接続が切れた場合は500 ms後に再アドバタイズします。

### LoRa

ラップ開始・確定時に、BLEと同じASCIIペイロードを送信します。`SendFrame()`の成功ログは主にペイロード長エラーがないことを示すもので、無線区間の到達を保証するものではありません。

| ライブラリ / ファイル | 用途 |

## 実装上の要点

- 割り込みは遮光の開始・終了時刻だけを記録し、重い判定は`loop()`で行います。
- 時刻は`esp_timer_get_time()`のμs単位で保持し、遮光時間とラップ時間の精度を確保しています。
- ISRと`loop()`間の共有状態はESP32の`portMUX_TYPE`で保護しています。
- LED、ブザー停止、LCD更新、BLE再アドバタイズは、初期化時以外は非ブロッキングで動作します。
